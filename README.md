The last text message a phone sends at one percent battery, in the voice of the dying phone itself:

> 1% left and I'm spending it texting you instead of ringing your alarm. Sweet dreams — I'll be a brick by morning.

113 characters, under the 200-character limit. The joke: the phone burns its final percent on a goodbye text instead of the alarm it was supposed to ring — and it knows it will be a brick by morning.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`, falling back to `$OUTPUT_DIR/entry.txt` for local testing), mode 0644, and prints the same line to stdout.
